# 文芽作文

面向中小学生的作文学习平台。精选范文、好词好句素材、可操作的写作方法。

## 状态

可上线版本（静态站，零构建）。

## 页面

| 文件 | 说明 |
| --- | --- |
| `index.html` | 首页：定位、四个入口、精选范文、今日练笔 |
| `essays.html` | 范文库：按年级/体裁筛选 + 关键词搜索 |
| `essay.html` | 范文详情：正文 + 逐篇点评 + 相关推荐（`?id=`） |
| `materials.html` | 素材库：写景/人物/情感/说理句子分类 |
| `tips.html` | 写作方法列表 |
| `tip.html` | 方法详情（`?id=`） |
| `about.html` | 平台介绍 |
| `404.html` | 404 页 |

## 结构

```
assets/css/style.css   样式系统（CSS 变量 + 响应式）
assets/js/data.js      数据：12 篇范文、8 组素材、6 篇方法
assets/js/app.js       渲染、筛选、搜索、详情页逻辑
.nojekyll              关闭 Jekyll 处理，供 GitHub Pages 使用
```

## 本地预览

```bash
python -m http.server 8123
# 打开 http://127.0.0.1:8123
```

## 分支与发布

| 分支 | 用途 |
| --- | --- |
| `main` | 发布分支，GitHub Pages 从此分支根目录部署 |
| `dev` | 开发分支 |

发布流程：在 `dev` 上开发验证 → 合并到 `main` → Pages 自动更新。
